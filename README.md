**按月、按小时、包年、抢占式：计费方式怎么选**

按月租是最常见的方式，适合连续运行超过一周的任务。LightLayer 的 GPU 服务器即采用月付制，配置里已包含内存和存储，省去了单独计算附加资源的麻烦。👉 [查看 LightLayer 各配置的月付价格](https://account.lightlayer.net/?affid=74)

如果任务持续时间短、不确定用多久，按量付费更灵活。按小时计费常用“月费 ÷ 730 小时”估算小时单价。单次运行不到 10 小时，按量付费通常比包月划算；连续跑一周以上，转包月成本更低。

包年适合长期稳定的生产环境，部分云厂商包年首购折扣可以到 4 折起，但需要一次性锁定预算。包月价格通常是官网目录价的 4–6 折，具体折扣随活动和客户身份变化。

抢占式实例适合可中断的批处理任务，价格约为常规价的 1–3 折，但实例可能随时被回收。离线渲染、数据预处理这类能容忍中断的工作可以选择，在线服务慎用。

**标价之外还要花什么钱**

GPU 服务器的月费通常只包含计算资源，账单上还有几项容易被忽略的附加费用：

- **系统盘和数据盘**：云盘按容量计费，ESSD 盘每月几十元到几百元不等，取决于容量和性能等级。
- **公网带宽和 EIP**：如果需要外网访问，带宽和弹性公网 IP 是单独计费的，1Mbps 固定带宽大约几十元/月。
- **地域和库存**：同一实例在不同地域标价有差异，L20 等高端卡型在部分地域资源紧张，下单前要确认目标地域能创建实例。
- **热门卡排队**：A10 这类热门卡型经常需要排队等资源释放，实际可用时间可能比预期晚。

LightLayer 的报价以专用服务器整体计价，内存和存储已包含在配置中，网络带宽的具体额度和超额计费方式建议在下单前向销售确认清楚，避免账单出来才发现带宽是另算的。
